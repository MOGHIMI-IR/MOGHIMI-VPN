# راهنمای فارسی ستاره‌دادن به مخزن مقیمی V2Ray

ستاره‌دادن (Star) در GitHub رایگان است و برای حمایت از دیده‌شدن و توسعهٔ پروژه استفاده می‌شود.

## از گوشی یا کامپیوتر

1. وارد حساب GitHub خودت شو. اگر حساب نداری، [اینجا ثبت‌نام کن](https://github.com/signup).
2. صفحهٔ مخزن رسمی برنامه را باز کن:
   **https://github.com/MOGHIMI-IR/MOGHIMI-VPN**
3. بالای صفحهٔ مخزن، دکمهٔ **Star** را پیدا کن و یک‌بار روی آن بزن.
4. وقتی دکمه به **Starred** تغییر کرد، ستاره با موفقیت ثبت شده است.

## نکته‌ها

- برای ثبت ستاره باید وارد حساب GitHub شده باشی.
- اگر از قبل **Starred** می‌بینی، یعنی قبلاً ستاره داده‌ای.
- ستاره‌دادن رایگان است و به معنی خرید اشتراک یا پرداخت پول نیست.

**پیوند مستقیم مخزن:** https://github.com/MOGHIMI-IR/MOGHIMI-VPN
