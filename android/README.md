# Moghimi V2Ray for Android

اپلیکیشن بومی اندروید مقیمی V2Ray بر پایهٔ پروژهٔ متن‌باز v2rayNG و هستهٔ Xray.

## نسخهٔ اول

- اتصال واقعی از طریق Android VpnService و هستهٔ Xray؛ نمایش اجازهٔ VPN توسط خود اندروید و با تأیید کاربر.
- واردکردن دستی لینک یا متن، Clipboard، فایل و QR.
- پشتیبانی از پروتکل‌هایی که نسخهٔ پین‌شدهٔ v2rayNG پشتیبانی می‌کند، از جمله VLESS، VMess، Trojan، Shadowsocks، SOCKS، WireGuard و Hysteria2.
- تست تأخیر TCP و تست تأخیر واقعی اتصال برای سرورها.
- دریافت ورودی‌های فعال public.v2ray_entries از پروژهٔ فعلی Supabase.
- دریافت فایل‌های خصوصی از Storage با لینک امضاشده و موقت.
- همگام‌سازی در شروع برنامه، با دکمهٔ ابر و به‌صورت دوره‌ای در پس‌زمینه.
- کانفیگ‌های سایت در گروه اختصاصی «کانفیگ‌های سایت مقیمی» نگهداری می‌شوند؛ کانفیگ‌هایی که کاربر دستی اضافه می‌کند در گروه خودش باقی می‌ماند.

## ساخت APK

گردش‌کار GitHub Actions در .github/workflows/android-apk.yml سورس و submoduleهای پین‌شده را دریافت می‌کند، کتابخانهٔ TUN و فایل AAR هستهٔ Xray را آماده می‌کند، پچ برند و همگام‌سازی مقیمی را اعمال می‌کند، تست‌های واحد را اجرا می‌کند و APKهای معماری‌های مختلف را می‌سازد.

برای اجرای دستی: GitHub → Actions → Build Moghimi V2Ray APK → Run workflow.

فایل APKهای هر اجرا در بخش Artifacts همان اجرای GitHub Actions قرار می‌گیرد و فعلاً ۳۰ روز نگهداری می‌شود. این خروجی نسخهٔ بتا و debug-signed است؛ برای انتشار عمومی پایدار با قابلیت نصب به‌روزرسانی روی نسخهٔ قبلی، باید کلید امضای خصوصی ثابت به‌صورت GitHub Actions Secret تنظیم شود. کلید خصوصی نباید در مخزن عمومی قرار بگیرد.

## اتصال به Supabase

برنامه فقط از publishable key عمومی وب‌سایت استفاده می‌کند و فقط ردیف‌هایی را می‌خواند که RLS اجازهٔ خواندنشان را می‌دهد (is_active = true). هیچ service-role key یا رمز مدیر در برنامه وجود ندارد. ترافیک VPN از تونل اندروید به آدرس موجود در کانفیگ می‌رود و از Supabase عبور نمی‌کند.

همگام‌سازی دوره‌ای WorkManager وابسته به زمان‌بندی و محدودیت‌های باتری اندروید است و لحظه‌ای نیست؛ با بازکردن برنامه یا فشردن دکمهٔ ابر می‌توان فوراً همگام کرد.

## مجوز کد

هستهٔ VPN، سرویس VPN اندروید و بخش قابل‌توجهی از کلاینت بر پایهٔ 2dust/v2rayNG با مجوز GPL-3.0 است. سورس پین‌شده در android/upstream قرار دارد و پچ‌های مقیمی در همین مخزن نگهداری می‌شوند. اطلاعیه‌ها در android/THIRD_PARTY_NOTICES.md آمده‌اند.
