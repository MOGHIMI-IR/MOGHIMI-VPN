## 🎨 رابط کاربری نسخه 1.0.4

- سه تب فارسی: اتصال، کانفیگ‌ها و تنظیمات.
- صفحه اتصال اختصاصی با دکمه متحرک، وضعیت واقعی سرویس و نمایش کانفیگ انتخاب‌شده.
- انیمیشن‌های Compose و فونت Tanha به‌صورت محلی داخل APK.
- صفحه کانفیگ‌ها از قابلیت‌های موجود v2rayNG برای واردکردن، QR، ویرایش، حذف، اشتراک‌گذاری و تست سرورها استفاده می‌کند.

## ✨ امکانات نسخه فعلی

- اتصال واقعی VPN از طریق Android VpnService و هسته Xray.
- واردکردن دستی لینک یا متن، Clipboard، فایل و QR.
- پشتیبانی از پروتکل‌های پشتیبانی‌شده در نسخه پین‌شده v2rayNG، از جمله VLESS، VMess، Trojan، Shadowsocks، SOCKS، WireGuard و Hysteria2.
- تست تأخیر TCP و تست تأخیر اتصال سرورها.
- دریافت ردیف‌های فعال `public.v2ray_entries` از پروژه Supabase.
- دریافت فایل‌های خصوصی Storage با لینک امضاشده و موقت.
- همگام‌سازی هنگام شروع برنامه، با دکمه ابر و به‌صورت دوره‌ای.
- نگهداری کانفیگ‌های سایت در گروه اختصاصی «کانفیگ‌های سایت مقیمی»؛ کانفیگ‌های دستی کاربر در گروه خودش باقی می‌مانند.

## 🏗️ ساخت APK

گردش‌کار [android-apk.yml](../.github/workflows/android-apk.yml) سورس و submodule پین‌شده را دریافت می‌کند، کتابخانه TUN و فایل AAR هسته Xray را آماده می‌کند، پچ برند و همگام‌سازی مقیمی را اعمال می‌کند، تست‌های واحد را اجرا می‌کند و APKهای معماری‌های مختلف را می‌سازد.

برای اجرای دستی: GitHub → Actions → Build Moghimi V2Ray APK → Run workflow.

پس از موفقیت بیلد، APKها در [بخش Releases](https://github.com/MOGHIMI-IR/MOGHIMI-VPN/releases) منتشر می‌شوند. Artifacts هر اجرای GitHub Actions هم به‌صورت موقت نگهداری می‌شوند.

## 🔐 اتصال به Supabase و داده‌ها

- برنامه از publishable key عمومی استفاده می‌کند؛ این کلید، service-role نیست.
- فقط ردیف‌هایی درخواست می‌شوند که `is_active = true` باشند و RLS اجازه خواندنشان را بدهد.
- اطلاعات سفارش‌ها و اطلاعات خصوصی مدیریت از این کلاینت خوانده نمی‌شوند.
- ترافیک VPN از Android VpnService به آدرس داخل کانفیگ مسیریابی می‌شود و از Supabase عبور نمی‌کند.
- همگام‌سازی دوره‌ای به WorkManager و محدودیت‌های سیستم‌عامل وابسته است و تضمین اجرای دقیق در ساعت مشخص ندارد.

## 🔄 دریافت نسخه‌های جدید

برنامه خودش APK نصب یا به‌روزرسانی نمی‌کند. برای دریافت نسخه جدید، از گزینه «بررسی نسخه جدید» به سایت رسمی برو و نصب را از مسیر معمول اندروید انجام بده. خود برنامه مجوز نصب بسته‌ها را درخواست نمی‌کند.

## 🧪 وضعیت و امضای انتشار

نسخه فعلی **Beta 1.0.4** است. تست‌های واحد و ساخت APK در CI موفق بوده‌اند؛ اتصال واقعی و سازگاری با همه دستگاه‌ها باید روی گوشی واقعی آزمایش شود.

خروجی‌های فعلی debug-signed هستند. تا زمانی که keystore خصوصی ثابت برای امضای نسخه‌های انتشار تنظیم نشده باشد، ممکن است نصب بیلد جدید روی نسخه قبلی نیازمند حذف نسخه قبلی باشد؛ حذف برنامه ممکن است داده‌های محلی را پاک کند. فایل keystore و رمزهایش را هرگز در مخزن عمومی قرار نده.
